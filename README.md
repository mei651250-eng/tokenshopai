# Token中站站 (Token Hub)

> 企业级 AI API 网关与多租户 SaaS 管理平台

## 项目定位

"Token中站站"是一个面向企业和开发者的**多模型 AI API 网关及运营管理系统**，提供：

- 🔀 **多模型统一调度** — 接入国内外大模型，智能路由、自动降级、负载均衡
- 💰 **计费与财务** — 按量/套餐计费，多币种支付，对账报表
- 🏢 **多租户与权限** — RBAC 权限体系，数据隔离
- 🛡️ **安全与合规** — WAF 防火墙，数据脱敏，审计日志
- 📊 **监控与大屏** — 实时流量、Token 消耗、性能趋势可视化
- 🌍 **全球化** — 多语言、CDN 加速、多时区

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | **Golang** | 高并发网关+核心调度 |
| 后端(业务) | **Go / Java** | 复杂业务逻辑 |
| 前端 | **Vue 3 + TypeScript + TailwindCSS** | 管理后台+大屏 |
| 数据库 | **PostgreSQL** | 关系型主库 |
| 缓存 | **Redis** | 限流/扣费/会话 |
| 日志 | **ClickHouse** | 海量审计/大屏查询 |
| 配置 | **MongoDB** | 非结构化模型配置 |
| 网关 | **Apache APISIX** | API网关+自研插件 |
| 容器 | **Kubernetes** | 编排与调度 |
| 监控 | **Prometheus + Grafana** | 指标与告警 |

## ⚠️ 合规与风险提示

> **重要**：本项目涉及以下合规风险，开发和运营时务必遵守相关法律法规：

1. **VPN/代理模块**：在中国大陆，未经批准提供 VPN 服务违反《中华人民共和国计算机信息网络国际联网管理暂行规定》。建议：
   - 仅在合法授权的企业内网场景使用
   - 境外部署时遵循当地法律
   - 不面向个人用户提供代理服务

2. **大模型合规**：根据《生成式人工智能服务管理暂行办法》：
   - 提供大模型服务需完成算法备案
   - 不得生成违法违规内容
   - 需建立内容审核机制

3. **数据安全**：遵循《数据安全法》和《个人信息保护法》：
   - 脱敏处理用户数据
   - 跨境数据传输需安全评估
   - 建立数据分类分级制度
