# Token中站站 系统架构设计文档

## 1. 系统概览

"Token中站站"是一个企业级 AI API 网关与多租户 SaaS 管理平台，核心能力包括：

- 多模型统一接入与智能调度
- 精细化计费与财务管理
- 企业级多租户与权限控制
- 全链路安全防护与数据脱敏
- 实时监控与可视化大屏
- 全球化多语言与跨境优化

### 2.2 请求处理流程

```
Client → Nginx → WAF检查 → 认证(API Key/JWT) → 限流检查 → 配额检查
  → 协议转换 → 负载均衡选模型 → 代理转发 → 响应脱敏 → Token计算 → 扣费
  → 返回响应
```

### 2.3 流式请求处理

```
Client → Nginx → WAF → 认证 → 限流 → 协议转换 → 路由
  → SSE代理(逐chunk转发) → 累计Token → 流式扣费 → 完成回调
```

## 3. 核心模块设计

### 3.1 AI模型路由与调度

**协议转换**：
- 将各家API（OpenAI, Claude, 文心, 通义等）统一转换为OpenAI兼容格式
- 支持自定义模型接入（通过自定义协议转换器）

**智能路由策略**：
| 策略 | 说明 | 适用场景 |
|------|------|----------|
| 加权随机 | 按权重随机选择 | 默认策略 |
| 轮询 | 依次选择 | 均匀分配 |
| 最低延迟 | 选择延迟最低的模型 | 对延迟敏感 |
| 最低成本 | 选择成本最低的模型 | 对成本敏感 |
| 最高成功率 | 选择成功率最高的模型 | 稳定性优先 |
| 综合评分 | 综合延迟/成本/成功率 | 均衡策略 |

**降级与熔断**：
- 熔断器三态：Closed → Open → Half-Open
- 连续失败N次触发熔断
- 冷却期后自动半开
- 请求失败自动降级到备选模型

### 3.2 计费引擎

**计费模型**：
- 按量付费（Pay As You Go）：根据输入/输出Token × 单价
- 套餐制：预付费Token包
- 企业授信：后付费

**原子扣费**：
- Redis + Lua脚本保证原子性
- 幂等性：每个扣费请求有唯一交易ID
- 防超卖：扣费前检查余额
- 实时余额查询

**多币种**：
- 支持CNY, USD, EUR, JPY, KRW等
- 实时汇率转换
- 聚合支付：Stripe(全球), 支付宝, 微信支付

### 3.3 多租户与权限

**租户隔离**：
- 逻辑隔离：共享数据库，tenant_id字段隔离
- Schema隔离：同库不同Schema
- 物理隔离：独立数据库实例

**RBAC权限**：
- 超级管理员 → 租户管理员 → 部门管理员 → 开发者 → 只读 → API消费者
- 6级角色，20+权限项
- API Key级别权限控制

### 3.4 安全与合规

**WAF防火墙**：
- IP黑白名单
- 请求限流（令牌桶算法）
- Prompt注入检测（6条默认规则）
- SQL注入拦截
- 代码执行检测

**数据脱敏**：
- PII自动识别：邮箱、手机号、身份证、银行卡、信用卡等
- 正则匹配替换为占位符
- 响应还原：返回给用户时还原原始数据
- 支持自定义脱敏规则

**审计日志**：
- 全链路追踪（TraceID）
- API调用记录
- 配置变更记录
- 安全事件记录
- 存储至ClickHouse用于海量分析

### 3.5 监控与大屏

**实时指标**：
- QPS（每秒请求数）
- Token消耗速率
- 成功率/P99延迟
- 活跃连接数
- 模型健康状态
- 熔断器状态

**报警通道**：
- 钉钉/企微/飞书
- 邮件
- 短信
- 移动端推送

**大屏展示**：
- WebSocket实时推送
- ECharts可视化
- 支持全屏展示

### 3.6 全球化

**多语言**：
- 支持 zh-CN, en-US, ja-JP, ko-KR
- vue-i18n前端 + Go后端i18n
- 可扩展更多语言

**跨境优化**：
- 多区域部署（CN, US, EU, AP）
- CDN加速
- 就近路由

## 4. 数据库设计

### 4.1 PostgreSQL（主库）

核心表：
- users, api_keys, tenants
- model_configs
- billing_records, packages
- audit_logs（近期数据）
- role_permissions

### 4.2 Redis

用途：
- 余额存储与扣费（Lua脚本）
- 令牌桶限流
- API Key缓存
- 会话管理

### 4.3 ClickHouse

用途：
- 审计日志（海量写入）
- 监控指标聚合
- 大屏数据查询

### 4.4 MongoDB

用途：
- 模型配置（非结构化）
- 租户自定义配置
- 动态表单

## 5. 高可用设计

- 后端服务无状态，支持水平扩展
- Redis Sentinel/Cluster 高可用
- PostgreSQL 主从复制 + 自动故障转移
- 多副本部署 + HPA自动伸缩
- 跨区域容灾备份

## 6. 合规风险提示

> ⚠️ 本项目涉及以下合规风险：

1. **VPN/代理模块**：在中国大陆，未经批准提供VPN服务违反相关法规。仅建议在合法企业内网场景使用。
2. **大模型合规**：根据《生成式人工智能服务管理暂行办法》，需完成算法备案、内容审核。
3. **数据安全**：遵循《数据安全法》和《个人信息保护法》，跨境数据传输需安全评估。
